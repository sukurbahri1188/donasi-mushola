Setup Sinkronisasi Google Sheets

Lakukan sekali, data langsung tersinkron ke semua perangkat

1
Buka script.google.com → klik "Proyek baru"
2
Hapus kode default, lalu salin seluruh isi file kode_google_apps_script.gs yang ada di folder yang sama dengan file HTML ini. Tempel di editor Apps Script.
3
Klik Deploy → New deployment → Type: Web app
Execute as: Me | Who has access: Anyone → Deploy
4
Salin URL Web App yang muncul (format: https://script.google.com/macros/s/...)
5
Buka file HTML ini di editor teks (Notepad), cari baris:
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbyf9eCOtdcwWRSvsWD5PR1I2NerSfdoApMQ0PlHrf0HhEQX7x98osZVj_56UbQcV2df/exec'; Ganti PASTE_URL_APPS_SCRIPT_DISINI dengan URL yang sudah disalin. Simpan file.
Setelah setup: Data galeri, donatur, dan berita akan tersinkron otomatis ke semua HP/laptop yang membuka aplikasi ini. Satu Google Spreadsheet gratis dibuat otomatis sebagai database.
